# Reportes: campos de costos independientes

Se eliminó **Precio Unitario** de las columnas seleccionables del módulo Reportes.

Para el rol ADMINISTRADOR ahora se muestran tres checks independientes:

- Costo último
- Costo promedio
- Valor a costo promedio

Cada campo seleccionado aparece de forma independiente en:

- La tabla del reporte en pantalla.
- La exportación a Excel.
- La vista de impresión / PDF.

Los tres campos no se seleccionan automáticamente: el usuario decide cuáles incluir.

**Valor a costo promedio** corresponde a `existencia × costo_promedio`.

No requiere cambios de base de datos.
